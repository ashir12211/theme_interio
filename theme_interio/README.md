# Interio - Website Theme for Odoo 18

A sophisticated and fully responsive premium interior design theme. Our theme includes different unique Home pages Luxe, Crafted, Atelier, Vista and Ambient with 50 unique snippets. Perfect for architects, home decor, furniture stores, luxury living spaces, and minimal design studios.


## 🌟 Features

### Discover Unique Home Pages
- **Luxe** - Premium luxury living spaces design.
- **Crafted** - Minimal and refined design studios.
- **Atelier** - Professional home decor and architectural layout.
- **Vista** - Modern and spacious interior displays.
- **Ambient** - Luxury black theme.

### Design Components (50+ Unique Snippets)
- **Dynamic Hero Banners** - Eye-catching hero sections specific to each home page (Luxe, Crafted, Atelier, Vista, Ambient).
- **Project Portfolios** - Showcase your interior design projects with modern hover effects.
- **Services Grids** - Beautiful card-based interior services display.
- **Infinite Marquees** - Animated premium marquees for text and clients.
- **Designers & Team** - Showcase your interior designers and team members with stylish profiles.
- **About Us & Philosophy** - Engaging storytelling components.
- **Testimonials & Reviews** - Client reviews carousels and grids.
- **Pricing & FAQ** - Flexible pricing plans and accordion-style frequently asked questions.
- **Contact Forms** - Integrated get-in-touch sections tailored for each style.

## 📋 Requirements

- Odoo 18.0+
- Website Module (built-in)
- Web Editor Module (built-in)

## 🚀 Installation

### Manual Installation
1. Download the module
2. Extract to your Odoo addons directory:
   ```bash
   /path/to/odoo/addons/theme_interio/
   ```
3. Update the apps list:
   ```bash
   ./odoo-bin -u all -d your_database
   ```
4. Install from Apps menu

## 🎨 Usage

### Getting Started
1. After installation, go to **Website** menu
2. Click **Edit** to enter Website Builder mode
3. Click on **Blocks** (+ icon) in the left sidebar
4. Drag and drop desired sections from Interio Snippets to your page

### Available Snippet Collections

- **Luxe Snippets:** Hero, Projects, Creation, Process, Team, Services, Clients, Marquee, Contact.
- **Crafted Snippets:** Hero, Designers, About, Reviews, Pure, Projects, Marquee, Clients, Contact.
- **Atelier Snippets:** Hero, Philosophy, Key, Pricing, Follow Us, Project, Marquee, Get in Touch, Designers.
- **Vista Snippets:** Hero, About, Rooms, Gallery, Reviews, FAQ, Members, Marquee, Contact.
- **Ambient & Extra Snippets:** Various supplementary sections and components.

### Customization
All sections are fully customizable through the Odoo Website Builder:
- Edit text directly by clicking on it
- Change images by clicking on them
- Modify colors through the theme customizer
- Adjust layouts using drag & drop
- Add/remove snippet sections seamlessly
